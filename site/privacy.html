الخلاصةIn short

ورّاق لا يجمع مستنداتك ولا يرسلها إلى أي مكان. كل ما تكتبه يبقى على جهازك أنت. لا توجد حسابات، ولا تسجيل دخول، ولا إعلانات، ولا أدوات تتبّع أو إحصاء داخل البرنامج.

Warraq does not collect or upload your documents. Everything you write stays on your own device. There are no accounts, no sign-in, no ads, and no tracking or analytics inside the app.

أين تُحفظ مستنداتك؟Where are your documents stored?

  • برنامج ويندوز: في الملفات التي تحفظها بنفسك على جهازك (بصيغة .warraq أو Word أو PDF).
  • نسخة المتصفح: يُحفظ العمل تلقائياً داخل متصفحك على جهازك فقط (التخزين المحلي للمتصفح)، ولا يُرفع إلى أي خادم. إذا مسحت بيانات المتصفح تُمسح هذه النسخة، والملف الذي تحفظه بنفسك هو النسخة المعتمدة.
  • اللقطات (النسخ السابقة) تُحفظ داخل ملف المستند نفسه.
  • Windows app: in the files you save yourself (.warraq, Word or PDF).
  • Web app: work is auto-saved inside your browser on your device only (local storage) and is never uploaded. Clearing browser data removes it; the file you save is the master copy.
  • Snapshots (earlier versions) are stored inside the document file itself.

الاتصالات بالإنترنتInternet connections

لكي تكون واضحين تماماً، هذه هي الاتصالات الوحيدة التي قد تحدث، ولا يُرسل في أيٍّ منها محتوى مستنداتك (إلا كلمات البحث في زرّي الدرر السنية والترجمة حين تضغطهما بنفسك، كما هو موضّح أدناه):

  • التحقق من التحديثات (برنامج ويندوز): يتصل البرنامج بصفحة إصدارات ورّاق على GitHub ليعرف إن كانت هناك نسخة أحدث، ثم ينزّلها. يرى GitHub في هذه الحالة عنوان IP الخاص بجهازك ورقم إصدار البرنامج.
  • الموقع ونسخة المتصفح: مستضافان على GitHub Pages، ويُحمَّل الخط من Google Fonts، فيرى كلٌّ منهما عنوان IP كما يحدث مع أي موقع. وتسأل الصفحة الرئيسية واجهة GitHub (api.github.com) عن رقم آخر إصدار وحجم ملف التثبيت لتعرضهما، فيرى GitHub عنوان IP كذلك. برنامج ويندوز يحتوي الخطوط بداخله ولا يحتاج Google Fonts.
  • الروابط الخارجية (مثل صفحة الإبلاغ عن مشكلة) تُفتح في متصفحك فقط عندما تضغط عليها.
  • زرّا «ابحث في الدرر السنية» و«الترجمة الإنجليزية» (في نافذتي الحديث والتحقق من الأحاديث): عندما تضغط أحدهما بنفسك فقط، يفتح موقع dorar.net أو sunnah.com في متصفحك ومعه كلمات البحث (أول ١٢ كلمة تقريباً من نص الحديث المعروض أو المكتوب، بلا تشكيل) أو اسم الكتاب ورقم الحديث؛ هذا هو الاستثناء الوحيد الذي قد يخرج فيه جزء من نصّك، وبقرارك أنت. مكتبة الأحاديث نفسها موجودة داخل البرنامج ولا تحتاج إنترنت.
  • زر «جلب البيانات» بالـDOI (في نافذة المرجع): عندما تضغطه بنفسك فقط، يُرسَل رقم الـDOI الذي كتبته إلى خدمة api.crossref.org لجلب بيانات المرجع (العنوان والمؤلفين والمجلة…)، ولا يُرسل أي شيء من نص مستندك.

To be fully transparent, these are the only connections that may happen, and none of them sends your document content (except the search words of the Dorar and translation buttons when you click them, as described below):

  • Update check (Windows app): the app contacts Warraq's release page on GitHub to see if a newer version exists, then downloads it. GitHub sees your IP address and the app version.
  • Website and web app: hosted on GitHub Pages, with the font loaded from Google Fonts, so each sees your IP address as with any website. The home page also asks the GitHub API (api.github.com) for the latest version number and installer size to display them, so GitHub sees your IP address there too. The Windows app bundles its fonts and does not use Google Fonts.
  • External links (such as the problem-report page) open in your browser only when you click them.
  • The “Search on Dorar” and “English translation” buttons (in the hadith and verify-hadiths dialogs): only when you click one of them, it opens dorar.net or sunnah.com in your browser with the search words (about the first 12 words of the shown or typed hadith, without diacritics) or the book name and hadith number. This is the only case where part of your text may leave your device, and only by your choice. The hadith library itself is bundled and works offline.
  • The DOI “Fetch details” button (in the reference dialog): only when you click it, the DOI you typed is sent to api.crossref.org to fetch the reference details (title, authors, journal…). Nothing from your document text is sent.

الإبلاغ عن المشكلاتReporting problems

صفحة الإبلاغ عن المشكلات والاقتراحات موجودة على GitHub وهي عامة، ويخضع استخدامها لسياسة خصوصية GitHub. لا ترفع فيها ملفات أو صوراً تحتوي على بيانات شخصية أو أجزاء من رسالتك.

The problem-report page is on GitHub and is public, governed by GitHub's privacy policy. Please don't attach files or screenshots with personal data or parts of your thesis.
