سياسة توقيع الكودCode signing policy

توقيع الكود مجاني، تقدّمه SignPath.io، والشهادة صادرة عن SignPath Foundation.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

ما الذي يُوقَّع؟What is signed

يُوقَّع ملف تثبيت ورّاق لويندوز (Warraq-Setup-x.y.z.exe) والبرنامج الذي يثبّته. تُبنى كل نسخة موقّعة آلياً على GitHub Actions من الكود المصدري المنشور في مستودع ورّاق، ولا يُوقَّع أي ملف بُني على جهاز شخصي.

The Warraq Windows installer (Warraq-Setup-x.y.z.exe) and the application it installs. Every signed build is produced automatically by GitHub Actions from the public source code in the Warraq repository; nothing built on a personal machine is signed.

أدوار الفريقTeam roles

  • المؤلفون (Authors): MidoMicro
  • المراجعون (Reviewers): MidoMicro، ويراجع كل تعديل يأتي من خارج الفريق (Pull Request) قبل دمجه.
  • المعتمدون (Approvers): MidoMicro، ويوافق يدوياً على كل طلب توقيع.

يستخدم كل أعضاء الفريق التحقق متعدد العوامل (MFA) على GitHub وعلى SignPath.

  • Authors: MidoMicro
  • Reviewers: MidoMicro, who reviews every change from non-committers (pull requests) before it is merged.
  • Approvers: MidoMicro, who manually approves every signing request.

All team members use multi-factor authentication on GitHub and SignPath.

الخصوصيةPrivacy

لا ينقل ورّاق أي معلومات إلى أنظمة أخرى على الشبكة، إلا إذا طلب ذلك المستخدم أو برنامج التثبيت. الاتصال الوحيد التلقائي هو التحقق من وجود نسخة أحدث على صفحة إصدارات ورّاق في GitHub. التفاصيل الكاملة في سياسة الخصوصية.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The only automatic connection is the update check against Warraq’s GitHub releases. See the full privacy policy.

الإلغاء والإبلاغUninstall and reports

يمكن إلغاء تثبيت ورّاق في أي وقت من إعدادات ويندوز (التطبيقات ← ورّاق ← إلغاء التثبيت). وللإبلاغ عن أي مشكلة أو ملف موقّع مشتبه به، استخدم صفحة الإبلاغ.

Warraq can be uninstalled at any time from Windows Settings (Apps → Warraq → Uninstall). To report a problem or a suspicious signed file, use the issue tracker.
